# UniLoop Marketplace

uild a responsive web app called "UniLoop", a student-only marketplace where college students can buy, rent, sell, or exchange used items (books, calculators, cycles, furniture, gadgets).Tagline: "Buy it. Use it. Loop it."

 

Pages: landing page, sign up/login with college email verification and "Verified Student" badge, browse page with search and filters (category, buy/rent/exchange, price, campus), item detail page, list-an-item form, user dashboard, and profile with ratings.

 

Features: in-app chat, ratings and reviews, wishlist, campus-based filtering.

 

Design: clean, youthful, mobile-first, teal/green with orange accent, circular loop motif in the logo.

 

Tech: React, Tailwind, Supabase. Use realistic sample data.
